Carbon Connect (MCP)Not connected

Passes every tool Carbon Connect publishes (product sourcing, configuration, quotes and draft orders) through to staff MCP tokens as carbon_* tools. Each token gets only the Carbon tools granted to it on Settings > MCP tokens. The sign-in requests all five Carbon scopes.

Not connected. No Carbon tools are offered to any token until an admin signs in.

Sign in with the Carbon Connect account PSA should act as. PSA registers itself with Carbon on the first Connect.

While this is off, or Carbon is not connected, no token can list or call a carbon_* tool and the daily catalogue sync (06:07) is skipped.
