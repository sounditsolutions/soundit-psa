Huntress EDR / ITDRConnected

Syncs EDR, ITDR, and SAT license counts from Huntress for billing. Runs daily at 05:00 or on demand.

Setup:
  1. In Huntress, create a user API key for the Huntress user the PSA should act as. (Huntress has deprecated the account-level API key.)
  2. The key carries that user's permissions in Huntress. A read-only user's key gives reads only. Resolving SOC escalations needs a user whose role may resolve them.
  3. Enter the API key and API secret below and click Save, then Test Connection.
  4. Click Organization Mapping to map Huntress organizations to your clients. Use Auto-Match by Name for bulk matching.
  5. Only mapped organizations will have their licenses synced. Unmapped organizations are ignored.
Shared Huntress accounts: If multiple MSPs share a Huntress account, each MSP maps only their own clients' organizations. Unmapped orgs are skipped during sync.
